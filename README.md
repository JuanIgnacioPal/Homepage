## 🏆 Proyecto destacado

### 📈 Análisis del Mercado Chileno de Seguros de Vida

Proyecto de Business Intelligence con datos sintéticos que simula el análisis competitivo, financiero y operacional de compañías de seguros de vida en Chile.

El proyecto aborda indicadores como prima directa, participación de mercado, crecimiento, siniestralidad, eficiencia operacional, rentabilidad y solvencia.

**🚧 Estado:** En desarrollo

**⚙️ Stack planificado:** Excel · Power Query · SQL · Power BI · DAX
